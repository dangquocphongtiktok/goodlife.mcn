# Goodlife Media — 3D Interactive Medical Branding Website

Website giới thiệu giải pháp truyền thông y khoa toàn diện & thiết kế Sensory Design đa giác quan cho Bác sĩ và Quản lý phòng khám.

## ✨ Công Nghệ
- **3D Engine**: Three.js (Mô hình chuỗi xoắn DNA sinh học & không gian kiến trúc y khoa)
- **Animation**: GSAP + WebGL Render Loop
- **Styling**: Tailwind CSS & Glassmorphism Design
- **Form Dispatch**: FormSubmit AJAX (Gửi trực tiếp email về `goodlife.mcn@gmail.com`)
- **Direct Contact**: Nút Zalo nổi 3D (Hotline `0918 600 310`)

## 🚀 Triển Khai (Deploy)
Website thuần static (HTML5/CSS3/JavaScript ES6), không cần backend server phức tạp.
Có thể triển khai tức thì trên **Vercel**, **GitHub Pages**, hoặc **Cloudflare Pages**.
